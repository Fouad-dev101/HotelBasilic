# Hotel Basilic — Digital Hospitality Concept

A complete, frontend-only website concept for **Hotel Basilic**, Al Hoceima, Morocco. The project is an independent demonstration prepared by a developer and is **not** the hotel’s official website.

The design direction is cinematic Mediterranean luxury: oversized editorial serif typography, warm ivory and midnight-navy sections, restrained champagne accents, asymmetric image compositions, and calm, purposeful motion.

---

## 1. Project overview

- **Business:** Hotel Basilic, 131 Avenue Abdelkrim El Khattabi, Al Hoceima 32000, Morocco.
- **Phone:** +212 539 98 00 83.
- **Publicly listed facilities:** 41 rooms, 5 suites, restaurant, café, pâtisserie, panoramic terrace, free Wi-Fi, free parking, breakfast, air conditioning, 24-hour reception, non-smoking rooms, family rooms.
- **Stack:** React 18, Vite, TypeScript, Tailwind CSS, Lucide React.
- **Languages:** French (primary), English, Arabic with RTL layout.
- **Nature:** frontend-only demonstration. No database, no backend, no real reservation processing.

> All room categories, descriptions, photographs and some operational details are illustrative and must be replaced or confirmed before any commercial launch.
